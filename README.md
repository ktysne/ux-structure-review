# ux-structure-review

UI の画面構造（まとまりと優先順位）に関する 7 つの UX 規則をチェックし、対象アプリの文脈に合わせて適用するためのエージェントスキルです。
Claude Code と Codex のどちらでも使えます。

利用者が画面のどこを見て、どれを押せばよいかを、まとまりと優先順位の構造から判断できるかを点検し、足りなければ補います。

## 7 つの規則

| 番号 | 規則 | 目的 | 対象となる構造 |
|---|---|---|---|
| 01 | 関連を近づけ、違いを離す | 関連の有無を距離と整列から読み取れるようにする | 情報のまとまり、余白、整列、面の内側の配置 |
| 02 | 同じ役割を同じように見せる | 見た目の規則から同じ役割をすばやく見つけられるようにする | 繰り返し要素、同種の操作、同じ役割の表示 |
| 03 | 異なる役割を面で分ける | 役割の違う情報を混同せずに扱えるようにする | 複数の責務や文脈を持つ画面の区画 |
| 04 | 次の操作を一つに絞る | 次に進む操作を迷わず選べるようにする | 複数の操作が並ぶ画面、フォーム、フローの操作列 |
| 05 | 情報の階層で読む順番を作る | 見出しから詳細へ読む順番を作り、内容の関係を追えるようにする | ページ見出し、セクション見出し、説明、補足、左端の整列 |
| 06 | 手順と関係を配置でつなぐ | 手順や関係の向きと順序を誤解なく読み取れるようにする | ステップ、依存関係、フロー、接続線、配置順 |
| 07 | 重要な要素を背景から際立たせる | 注目すべき要素と背景を区別し、操作対象へ集中できるようにする | ダイアログ、ポップオーバー、重要な通知、重なり合う要素 |

各規則の目的、チェック観点、対象外の条件、別の表現で満たす条件、実装上の注意は [skills/ux-structure-review/references/rules.md](skills/ux-structure-review/references/rules.md) にあります。

## このスキルの考え方

守るのは規則とその目的であり、特定の見た目ではありません。
規則を機械的に当てはめると、単純な画面に区画や操作を増やしたり、既存のデザインシステムと異なる表現を持ち込んだりして、かえって構造を読みにくくします。
そのため、このスキルは次の順で適用の可否を判断します。

1. その構造が実際に必要か
2. 利用者が区別や優先順位を必要とするか
3. 既存のデザインシステムや UI 規約と衝突しないか
4. 実装コストに見合うか

判定は「満たす」「満たさない」「適用しない」「情報不足」の四つに分けます。
チェック観点どおりの表現がなくても、別の手段で目的を達成できる場合は「適用しない」にせず、その手段の有無で判定します。
見た目が整っている画面でも、規則ごとに操作の成功を別に確認します。
整った見た目は使いやすい印象を与えますが、印象と実際に迷わず操作できることは一致しません。
読み込み中、空、0 件、失敗、権限不足、保存状態、削除、完了、入力不備など状態の設計は ux-state-review に譲ります。

同じ立ち位置の姉妹スキルが三つあります。

- `ux-state-review`：UI の状態（待つ、空、失敗、権限不足、削除、完了、入力不備）
- `ux-readability-review`：文字と文言（読みやすさ）
- `ux-load-review`：記憶、判断、操作の負担

## インストール

使うエージェントのスキルディレクトリに `skills/ux-structure-review` を置きます。
スキルの形式（`SKILL.md` と参照ファイル）は Claude Code と Codex で共通です。

```bash
git clone https://github.com/ktysne/ux-structure-review.git
```

ユーザー共通で使う場合：

```bash
# Claude Code
cp -r ux-structure-review/skills/ux-structure-review ~/.claude/skills/
```

```bash
# Codex
cp -r ux-structure-review/skills/ux-structure-review ~/.codex/skills/
```

特定のプロジェクトだけで使う場合は、そのリポジトリの `.claude/skills/`（Claude Code）または `.codex/skills/`（Codex）にコピーします。

クローンしたリポジトリをそのまま参照したい場合は、コピーの代わりにシンボリックリンクを張っても動作します。

## 使い方

スキルは、画面のまとまり、繰り返し要素の役割、主操作、見出しの階層、手順や関係、ダイアログや重なりの構造を含む作業で自動的に使われます。
明示的に使わせる場合は、Claude Code では `/ux-structure-review` と入力し、Codex ではスキル名 `ux-structure-review` を指示に含めます。

例：

- 「申請一覧画面と申請フォームの構造をレビューして」
- 「複数の操作が並ぶ設定画面で、次に押す操作が分かる構造に直したい」
- 「手順画面の見出しと接続を、利用者が順番どおりに追えるようにしたい」

レビュー結果は、規則ごとの判定表、優先して直す項目、開発者の判断を要する項目の三つに分けて報告されます。
